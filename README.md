# SNAKE MMA

لعبة أركيد خفيفة مستوحاة من Snake الكلاسيكية، مبنية باستخدام HTML وCSS وJavaScript وCanvas دون مكتبات خارجية.

## التشغيل محليًا

يمكن فتح `index.html` مباشرة لتجربة اللعب الأساسية. لتجربة تثبيت PWA وService Worker، شغّل المشروع من خادم محلي أو انشره عبر HTTPS.

## النشر على GitHub Pages

1. أنشئ مستودعًا عامًا باسم `snake-mma` على GitHub.
2. ارفع جميع محتويات هذا المجلد إلى جذر المستودع، بحيث يكون `index.html` في الصفحة الرئيسية للمستودع.
3. افتح Settings ثم Pages.
4. من Build and deployment اختر Deploy from a branch.
5. اختر `main` والمجلد `/ (root)` ثم Save.
6. انتظر اكتمال النشر، وسيظهر رابط الموقع في صفحة Pages.
7. افتح الرابط في Chrome على Android، ثم من قائمة المتصفح اختر Install app أو Add to Home screen.

## ملاحظات

- لا يوجد تسجيل دخول أو قاعدة بيانات أو اتصال بخادم لعب.
- لا تحفظ اللعبة النقاط أو سجل الجولات بعد إغلاقها.
- ملفات التطبيق الأساسية مخزنة عبر Service Worker بعد أول تحميل ناجح.
- يلزم HTTPS أو localhost لتفعيل Service Worker.
- ملف APK سيكون مرحلة منفصلة باستخدام Capacitor بعد اختبار نسخة الويب.
