# SNAKE MMA — Version 2

لعبة Arcade خفيفة تعمل بالمتصفح، مع دعم PWA والتشغيل دون اتصال بعد أول تحميل ناجح.

## تحديثات النسخة الثانية
- إبقاء ثلاثة أطعمة في الملعب قدر الإمكان، مع إعادة ملء الطعام تلقائيًا بعد الأكل.
- أنواع طعام ونقاط متنوعة: 10 و20 و25 و50.
- مستويات متتابعة كل 100 نقطة، مع زيادة تدريجية للسرعة وإضافة عقبات في المستويات المتقدمة.
- حفظ أعلى نتيجة وأعلى مستوى وإجمالي الطعام وعدد الجولات محليًا على الجهاز عبر LocalStorage.
- تحديث مسارات PWA لتناسب GitHub Pages داخل `/SNAKE-MMA/` وتغيير اسم ذاكرة التخزين المؤقت لإجبار تحديث ملفات النسخة السابقة.

## النشر
ارفع محتويات هذا المجلد إلى جذر مستودع GitHub Pages الحالي، مع الحفاظ على مجلد `assets` كما هو. فعّل Pages من الفرع `main` والمجلد `/(root)`.

## ملاحظات
- الإحصائيات محفوظة على نفس المتصفح والجهاز فقط، ولا يوجد تسجيل دخول أو خادم أو مزامنة.
- مسح بيانات الموقع أو المتصفح قد يمسح الإحصائيات.
- بعد النشر، افتح الموقع مرة متصلة بالإنترنت لتحديث ملفات PWA، ثم اختبر فتحه دون اتصال.
